## Requirements

- **Bun 1.4.4 or newer.** The package engines field rejects older Bun versions.
- **A Discord user token.** This is a selfbot, not a bot application token. Read [Token safety](/docs/getting-started/token-safety) before you start.
- **Optional:** TypeScript 5.5 or newer for typed projects.

<Callout type="error" title="Node.js is not supported">
  The package is Bun-only. It uses Bun for installation, tests, type checking, formatting, and the build. Use Bun
  for the application that imports it as well.
</Callout>

## Install

```sh
bun add discord-ts-selfbot
```

The package name is `discord-ts-selfbot`, not the old `discord.js-selfbot-v13`. The published major is `14`, which tracks the `discord.js@14.28.1` API baseline.

## Import

The package is ESM-first. Import the classes and enums by name:

```ts
import { Client, Events } from 'discord-ts-selfbot';
```

The source tree also keeps CommonJS files for compatibility with the original fork, but new code should use `import`.

## Verify the install

Create a small file and run it with Bun:

```ts
import { Client, version } from 'discord-ts-selfbot';

console.log(`discord-ts-selfbot ${version}`);
console.log(typeof Client);
```

```sh
bun run check.ts
```

## Project layout

If you are working inside this repository:

```sh
bun install
bun run check
bun run test
bun run docs
```

The docs site is a static Next.js app in `apps/docs`. The library lives in `packages/discord-ts-selfbot`.
