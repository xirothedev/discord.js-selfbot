This example enables message, channel, and reaction partials, then prints the gateway status when the client is ready.

## Run it

```sh
DISCORD_TOKEN=your-token bun run --cwd apps/examples-ts events
```

## What it shows

- The numeric `Partials` runtime enum and the string `PartialTypes` type.
- Both `Events.ClientReady` and `Events.CLIENT_READY`.
- Reading `client.ws.status` through the `Status` enum.
- A message handler that ignores the account&apos;s own messages.
