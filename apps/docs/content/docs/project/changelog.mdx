## Unreleased

### Added

- Typed `RESTManager.request()` and `RequestOptions`. The typed router and `client.rest.request()` return typed promises.
- `createRestClient({ token })` for gateway-free REST use. Direct `client.token` assignment is documented. `login()` stays gateway-only.
- `http.fetch` override plus built-in HTTP and SOCKS5 proxy transport. Bun ignores the undici `dispatcher`, so proxying no longer relies on it.
- `maxRateLimitRetries` (default `2`). `RateLimitError` gains `retryAfter` in ms, `remaining`, `reset`, and `scope`.
- `MissingTokenError`, thrown before any HTTP when the token is empty or missing. It is terminal and never retried.
- New guides: rest-only use, proxies, rate limits, errors.
- `HTTPError.status`, `HTTPError.cause`, and `HTTPError.retryable`.

### Changed

- `HTTPError.status` now carries the HTTP status; `code` keeps the Discord JSON code or a synthetic `500`. Non-JSON 401 pages no longer look like 500s.
- 429 retries are bounded. `rejectOnRateLimit` still throws before waiting.
- `RESTManager.destroy()` closes the dispatcher and clears handlers. `Client#destroy` calls it.
- One client can mix API versions per request via `options.version`. Routes derive from the path when `options.route` is empty.
- Package exports carry `types`, `bun`, and `default` conditions. The runtime stays Bun-only.
- Docs index states version `14.0.2`. The agent docs corpus is regenerated.
- REST and gateway default to API v9, which is the version the official Discord client uses. `http.version` and `ws.version` stay configurable.
- Existing client property values now match Discord desktop `1.0.9267` (build `667580`). No new client property fields were added.
- The package version does not change for this update.

### Notes

- This improves request parity with the official client. It does not guarantee that Discord will not detect automation.

## 14.0.0 — 2026-11-08

The first release of the Bun + Turborepo monorepo.

### Added

- Bun workspaces and Turborepo task graph.
- TypeScript source for every module under `src/`.
- `Events`, `Partials`, and `Status` enums.
- 11 `*BitField` aliases.
- v14 builder exports and v13 aliases.
- 20 interaction, component, and manager classes.
- `Message#awaitMessageComponent` and `Message#createMessageComponentCollector`.
- `InteractionCollector` and the `INTERACTION_CREATE` gateway wiring.
- `Client#generateInvite`, `Client#fetchStickerPacks`, and `Client#deleteWebhook`.
- Message extras: `report`, `markUnread`, `markRead`, `suppressEmbeds`, `removeAttachments`.
- Account edits: `setBanner`, `setHypeSquad`, `setAccentColor`, `setAboutMe`, `setPronouns`, `setGlobalName`, `setSamsungActivity`, `fetchBurstCredit`.
- Guild settings, vanity, community, and top emojis.
- Message and member search.
- Billing, Nitro/OAuth, sharding, and intents.
- Friend invites.
- Voice, DM/group calls, and recording.
- Fake Discord HTTP and WebSocket test server.
- Fumadocs documentation site.

### Changed

- Package name is `@discord-selfbot/core`, version `14.0.0`.
- Runtime is Bun 1.4.4 or newer. Node.js is not supported.
- The source tree is TypeScript-only. Bun runs the `.ts` source directly.
- Docs moved to `apps/docs`. The legacy docgen and TypeDoc HTML artifacts are removed from the site.

### Deprecated

- v13 builder aliases: `ActionRow`, `Button`, `SelectMenu`, `Embed`, `Attachment`, `TextInput`.
- `RelationshipManager#addFriend`, `#deleteRelationship`, `#sendFriendRequest`, and `#addBlocked` remain stubbed and marked `@deprecated` / `@experimental`.

### Security

- User tokens are never needed by the test harness.
- The release workflow uses SHA-pinned GitHub Actions.
- `bun publish` runs without `--provenance` because Bun 1.4.4 rejects the flag.
